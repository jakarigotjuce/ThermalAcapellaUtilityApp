Windows 10/11 (64-bit) desktop application.

- **AcapellaDownloaderSetup.exe:** double-click to install; no separate Python setup is required.
- **Portable ZIP:** extract the entire folder and launch `AcapellaDownloader.exe` inside it. Keep `AcapellaWorker.exe` and `_internal` alongside it.
- YouTube search/download and local audio input; local Demucs vocal isolation; estimated key/BPM.
- The first vocal separation downloads a Demucs model and can require substantial CPU time.
- Installer is not code-signed. Windows may display an unknown-publisher warning.

Use audio you own or have permission to download/process.
